# Sistema de Controle de Equipamentos
## Sobre o Projeto
Plataforma digital desenvolvida para modernizar e otimizar a gestão de equipamentos da E.E. Luiz Bianconi. O projeto tem como objetivo substituir o uso de planilhas físicas por um sistema web eficiente, centralizando o controle de entrada e saída de materiais. A iniciativa visa facilitar a organização do inventário em tempo real, proporcionando maior controle e agilidade para a gestão escolar.

## Funcionalidades
 * *Controle de Movimentação:* Registro preciso de retirada e devolução de equipamentos.
 * *Atribuição de Responsabilidade:* Vinculação direta de cada movimentação ao professor responsável.
 * *Gestão por Turnos:* Identificação e filtragem de uso dos equipamentos por turno de aula.
 * *Monitoramento de Quantidades:* Controle exato do volume de itens em uso e disponíveis.
 * *Inventário em Tempo Real:* Painel atualizado instantaneamente para visualização da disponibilidade do acervo, prevenindo perdas e conflitos de agendamento.

## Tecnologias Utilizadas
O projeto foi construído utilizando as seguintes tecnologias:
 * *Frontend:* HTML, CSS, JavaScript
 * *Backend:* Node.js
 * *Banco de Dados:* PostgreSQL (gerenciado via Supabase)
 * *Hospedagem e Deploy:* Vercel (Frontend/Backend) e Supabase (Database/BaaS)
